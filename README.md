# Toko Wiwid — POS & Operasional

Fondasi aplikasi kasir untuk operasional retail/grosir.

## Stack
- Next.js App Router
- React dan TypeScript
- PostgreSQL dan Prisma direncanakan untuk fase database
- Integrasi Accurate dipisahkan dari logika transaksi

## Menjalankan aplikasi
```bash
npm install
npm run dev
```
Buka http://localhost:3000.

## Pemeriksaan
```bash
npm run lint
npm run typecheck
npm run build
```
